## Design Studio (2026-11-16)
The Cover Generator page has two modes: **Generate with AI** (the original flow) and **Design Studio**.
- Code: `src/components/coverStudio/CoverStudio.js` (editor) and `src/components/coverStudio/backgrounds.js` (flat procedural templates, palettes, grain). Uses `fabric` v7.
- The canvas backing store is always 1800x900 and is scaled with CSS only, so the export is exactly what is on screen. Do not change the canvas size.
- Logos load from `/api/cover-generator/logo-preview/:symbol` with `crossOrigin="anonymous"`. Anything drawn on the canvas must be CORS-enabled or the export is blocked.
- Use gradients and paths only in `backgrounds.js` (no `ctx.filter`, Safari does not support it).
- **Grain is never resized.** Fine (single-pixel) grain is the default the owner wants, and it only stays pattern-free when shown pixel for pixel; resizing it creates a woven ripple (moire). So the editor is three stacked layers inside `Stage`: `BgLayer` (1800x900 background, CSS-scaled, no grain), `GrainLayer` (one grain field at exactly the screen's device pixels, strength = CSS opacity), then the transparent fabric canvas (logos, text, watermark). The downloaded file is composed separately in `exportDataUrl()` with grain drawn at 1800x900. Do not put grain back into a CSS-scaled canvas. "Coarser grain" is the soft blurred variant. Thumbnails always use the soft variant.
- **Snapping must call `o.setCoords()` before measuring.** fabric moves the object to the pointer, fires `object:moving`, and only then refreshes its cached corners. Reading `getBoundingRect()` without refreshing gives the previous step's position, which made dragged logos stutter and lurch near every guide. Snapping can be turned off (Snap checkbox) or bypassed with Option/Alt.
- **Government seals** (their own "Seals" tab in the left panel; the owner could not find them as a switch inside Logos) come from `GET /api/cover-generator/seals` (only `grounded` entries with an `imageUrl`). A seal is a logo item with `studio.seal = true`: it starts large, at 22% opacity, sent to the back, and is skipped by the auto layouts. Seals are full-colour discs, so the single-tone modes use `monoEmblem()` (luminance to alpha) instead of a flat tint; always repaint items through `paintItem()`.
- **The owner uses Safari.** Fixed-ratio thumbnails use the `Thumb` padding-bottom box, never `aspect-ratio` on an image inside a scrolling grid (Safari collapses those rows into strips). Scrolling grids set `grid-auto-rows: max-content`. Check new UI in real Safari (`safaridriver`), and tell the owner before opening an automation window: touching it shows a "remotely controlled" prompt.
- Template house rules (owner feedback 2026-11-16): dark fields only, never white or light backgrounds. No hard colour blocks, panels, diagonal splits, overlapping discs or light beams. Soft glows, fine line work and grain are what the owner wants.
- The owner also removed Flow Lines, Guilloche, Halo and Veils, and the blue (Midnight Navy, Cobalt), green (Deep Teal, Forest), red (Oxblood), orange (Ember) and yellow (Amber Ink) palettes. Do not bring those back. A new cover starts on the owner's own colours (`DEFAULT_PALETTE`, id `signal`, "Violet and Aqua"): base black `#000000`, accent purple `#6a4cf5`, second aqua `#00fdb1` (set 2026-11-16, replacing Royal Violet as the default).
- **Contrast** (Background, Finish) is `applyContrast()` in `backgrounds.js`: an S-curve around the picture's own average brightness, applied to pixels (no `ctx.filter`) before the vignettes and grain, so it is in the export too. It pivots on the average because covers are dark; a mid-grey pivot would only darken them. Inputs are dithered by a fraction of a level so stretched gradients do not band. A newly loaded image resets it to 0.
- **Size and position** (Background tab, both studios) are `bg.zoom`, `bg.shiftX` and `bg.shiftY`, applied inside `renderBackground()` to the image or the template, so the live view and the export always agree. Shifts are a share of the cover's width and height. Whatever the picture no longer reaches is filled with the palette's base colour. The background is its own layer and is never selectable; keep it that way, the owner asked for sliders so it cannot be picked up by accident. "Centre on the open area" (`openArea()` / `centreBackground()` in `CoverStudio.js`) finds solid panels or stacks of framed photos against an edge, moves the middle of the background to the middle of what is left, and enlarges it only as far as needed to keep every edge covered. A new image keeps the position.
- In the AI backdrop tab, "Use my colours below instead of the style defaults" is ticked by default (owner 2026-11-16).
- **Studio fonts** are listed in `FONTS` (CoverStudio.js) and loaded in `studioFonts.js`. Families with `italic: true` get an Italic checkbox. Montserrat (all nine weights), Instrument Serif and Bebas Neue (one weight, capitals only, SIL Open Font License, added 2026-11-18) come from `@fontsource`. Added the same day, also from `@fontsource` (all SIL Open Font License): Geist (the package's family name is `Geist Sans`; the list shows it as "Geist" through the entry's `label`), Geist Mono, Plus Jakarta Sans and DM Sans. **Instrument Serif starts in italic when it is picked from the list** (owner 2026-11-18; `italicFirst` on its `FONTS` entry, applied in `pickFont` and the hover preview; the Italic tick box switches it off). **Instrument Serif is the only serif in the list** (owner 2026-11-18: Playfair Display, Source Serif 4, Newsreader, Fraunces and DM Serif Display were removed, packages included; do not add serifs back unasked). **Satoshi was asked for and NOT added:** Fontshare's ITF Free Font License v2.0 (17 Aug 2026, read 2026-11-18 at fontshare.com/licenses/itf-ffl) allows self-hosting for the licensee's own site but section 02 forbids making the font "available as a selectable font for third-party users" in a design tool or template editor, and forbids handing it to contractors. The same applies to every Fontshare closed-source font. A person can still download it from Fontshare themselves and add it under "Your own fonts". CMG Sans (a renamed Montserrat derivative, SIL Open Font License) is not on npm: its files are in `coverStudio/fonts/cmg-sans/` as latin subsets, with its special cuts (Wide, Wide Outline, Outline) exposed as separate families under "Display". The Rounded, Slab, Backslant and Mono Digits cuts were removed on 2026-11-18 at the owner's request (list entries, CSS and files). **Only publish fonts whose licence allows it:** the bundle is public, so any font added here is downloadable by anyone. On 2026-11-16 the owner also asked for Styrene A, Aeonik, Pilat Wide, HK Modular and Roc Grotesk; those are commercial and were NOT added (the copies on this Mac are trial files or have no known web licence). Add them only once the owner supplies licensed web-font files. Until then they are used through **"Your own fonts"** (Text tab, `userFonts.js`): the person adds font files from their own computer, the browser registers them with the FontFace API and remembers them in IndexedDB (`cg_studio_fonts`). Those files are never uploaded or bundled, so nothing commercial is published. Family, weight and italic are read from the file's own `name` and `OS/2` tables (file name as a fallback for woff/woff2).
- No emojis and no em dashes in UI copy.

## Interview Cover Studio (2026-11-16)
The third mode tab on the Cover Generator page. It is the same editor component (`CoverStudio.js`) mounted with `profile="interview"`, so the two never share a canvas or state, but they share the engine. Building blocks live in `coverStudio/interviewKit.js`.
- **Size is 1920x1080** (owner's call; article covers stay 1800x900). Inside the component use `W` / `H`, never `COVER_W` / `COVER_H`. `renderBackground()` takes `designW` / `designH`.
- **Guest photo** = one image object (`studio.kind === 'photo'`) whose picture is drawn by `paintPhoto()`: photo inside a circle, rectangle or polygon mask, optional rounded corners, the mask can be turned without turning the photo, zoom and pan inside the mask, colour / black and white / tint, colour behind a cut-out, border. Change settings through `setPhoto()` (it repaints and re-lays-out).
- **Name, title, label bar, and the ECOSYSTEM caption are ordinary objects that follow a parent** (`studio.attach = { to, role, rel, dx, dy }`). `layoutAttached(frame)` places them: the name is the larger line, and both are scaled down so they are never wider than the mask before they wrap. Hand edits (dragging a name, changing its size) are kept as offsets. Anything that moves or resizes a parent must call `layoutAttached`. **A guest sizes as one piece** (owner 2026-11-16: no scaling each part on its own): corner-dragging the photo, the "Whole guest" slider (shown for the photo and for its name or title), selecting the parts together and scaling the group, and "Size of every guest at once" in the Guests tab all go through the same layout. `takeHandEdits` tells a group move or group scale (the text rode along with its photo) apart from a real hand edit; without that check the text was scaled twice. The label bar is not selectable: it is redrawn under its photo, live during a group drag (`liveBarsRef`).
- **Name strip** (owner 2026-11-17): under the toolbar, one cell per guest that has a name plate, in reading order, with Name and Title fields and left / centre / right buttons (plus "Align all"). Clicking into a field selects that guest on the cover. Typing in a field (the strip or the Edit panel, both go through `setGuestTextOf`) applies the owner's rules: the line returns to the layout's size (`ATTACH_REL`: name 0.105, title 0.06 of the photo's width), which is its largest, and is made smaller only as far as needed to fit the plate's inner width; the title is also kept below the name's size. A line sized by hand on the cover is marked `attach.free` and is then left at whatever the person made it (even wider than the photo) until it is typed in a field again. An empty line takes no room, so a guest with no title gets a shorter plate.
- Switching a guest's text style to None stores the name and title (text, font, colour, size, offsets) in `studio.kept` and brings them back when the style is switched on again. Do not go back to recreating the "Guest Name" placeholders; the owner lost typed names that way.
- **Changing layout keeps the person's work** (owner 2026-11-17). `applyInterviewLayout` first runs `harvest()`: typed headline, subtitle, pill, "Brought to you by" and ECOSYSTEM text, the two slot logos, every guest's photo, name and title (reading order), and grain on the colour panel go into `carryRef`. The new layout is then built and filled with them, in the new layout's own positions and style. Content only: fonts, sizes and colours come from the new layout. A line counts as typed when it differs from `studio.seed` (the placeholder it was made with). Carried text is fitted into the room the layout's placeholder takes (`fitTo` in `makeText`). Layouts that show names in capitals keep the typed form in `studio.raw`. Anything the new layout has no place for (a third guest, a subtitle) stays in `carryRef` and returns with a layout that has one. Items made by a layout carry `studio.tpl`; items the person added themselves (extra text, shapes, logos) are left where they are, but guests always move into the new layout's guest places. "Start again with empty placeholders" in the Layouts tab clears the carry.
- **Photo background erase** (`photoCutout.js`, button in a guest's Edit panel; owner chose the free in-browser route on 2026-11-17). MODNet portrait model (`models/modnet.onnx`, 26 MB, Apache 2.0, from Hugging Face `Xenova/modnet` at commit fa2fa54, sha256 07c308cf...84df9) run with `onnxruntime-web` 1.16.3 (MIT, pinned exactly) as single-threaded WebAssembly. Nothing is uploaded; the model and runtime load only on first use. Input is the photo with its shorter side at 512 (sides multiples of 32), values scaled to -1..1; output is the alpha matte. Keep it worker-free and thread-free: the live policy has no `blob:` workers and no cross-origin isolation. The `.wasm` files are imported by relative path from `node_modules` because the package does not export them; upgrading onnxruntime-web past 1.16 changes its file layout, so do not bump it casually. The untouched photo is kept in `studio.srcOrig` for "Bring the background back". It is a people model: it does not work on logos or on pictures that are already cropped into a circle on a flat colour.
- **Drag and drop** an image file from the computer onto the cover (`onStageDrop`): on a guest it becomes that guest's photo, on an empty logo spot it fills it, anywhere else it is added as an image at that point. A dashed box shows where it will land.
- Guest names start in CMG Sans Bold (700) and titles in CMG Sans Regular (400) (owner 2026-11-17). The earlier automatic switch to Pilat Wide for names is gone.
- **Align tools** (`AlignTools`, `alignSelected`; owner 2026-11-17). In the toolbar (always there, greyed out until two or more items are selected, so the cover never jumps) and in the Edit panel for a multi-selection: line up left / centre / right / top / middle / bottom, and with three or more items space evenly left to right or top to bottom (the outer two stay put, the gaps become equal). A guest with its name, title and bar is one piece. The function drops the selection, moves each piece in cover coordinates, and selects the same items again.
- History stores true cover positions: `capture()` converts an item inside a multi-selection from selection-relative numbers with `util.qrDecompose(o.calcTransformMatrix())`. Without that, Undo after any change made while several items were selected threw them to the wrong place.
- **Elements tab** (interview studio; owner 2026-11-17): ready-made pieces listed in `INTERVIEW_ELEMENTS` (`interviewKit.js`) and built by `addElement`: Hosted by, three guest styles, Interview pill, Highlighted words, Brought to you by, Ecosystem logo. Every piece is made of ordinary items so a contractor can move, restyle or delete each part. Add new pieces to that list plus a case in `addElement` and a drawing in `drawElementThumb`.
- **Hosted by** (`addHost`): a round host photo (`studio.host`), with three attached parts: the words (`attach.role` `hostlabel`), the microphone badge (`hostmic`, a logo-kind image drawn by `hostMicBadge()` from the owner's reference: lime `#d2ff00` disc, black line microphone) and a handle (the ordinary `name` role, regular weight, allowed 1.4x the photo's width through `attach.wide`, default size kept in `attach.rel0`). `layoutAttached` places the words and badge on one line above the photo. `takeHandEdits` / `noteLayout` take a `picture` flag so the badge keeps its own offset and size like text does. A host is not one of a layout's guests: layout changes leave it in place, and "Size of every guest at once" skips it.
- **Toolbar Size** (`scalePieces`): sizes the selected piece as a whole about its centre. `piecesOf` resolves a selection to whole pieces: an attached part counts as its parent, and items sharing `studio.set` (the two halves of "Brought to you by") count together. With several items selected it sizes all of them. Parts are still sized one by one by dragging them on the cover.
- **Size of all guests together** (`scaleAllGuests`): a second slider under "Whole guest" in the Edit panel of a guest photo, name or title. It scales every guest (not a host) by the same factor measured from the selected guest, so guests given different sizes keep their difference, each stays in place, and the selection is kept. The Guests tab slider (`resizeAllGuests`) is different: it sets every guest to one width.
- **Ecosystem label** (the caption under a logo): starts at 4.6% of the logo width (`ATTACH_REL.caption`). `setCaption(frame, { size, spacing })` stores the size as `attach.rel` and the letter spacing as `attach.track`; while `track` is unset the letters are spread to the logo's width, and `spacing: null` goes back to that. Controls are in the logo's Edit panel ("Label under the logo") and in the label's own Edit panel (its Size and Letter spacing sliders call `setCaption`, not `change`, because `layoutAttached` recomputes both). Alignment is `attach.align` (left, center, right), set the same way: the label lines up with that edge of the logo. It shows only once the spacing is set by hand, since a spread label is as wide as the logo.
- **Most used logos** (interview studio; owner 2026-11-17): `MOST_USED_LOGOS` puts Hedera, HashPack, Solana, XDC and Canton, in that order, in their own section above "All logos" in the Logos tab and in a logo's Edit panel. The section hides while a search is typed.
- **Background removal for any image on the cover** (owner 2026-11-18): an image dragged onto the cover (or a file added in the Logos tab) is a `logo` item. Its Edit panel starts with "Background of this image": "Remove the background" (the same MODNet people cut-out guests have, `cutOutLogoPerson`; the picture keeps its size and place, no trimming) and "Remove plain background" (flat colour, `removeLogoBackground`, trims). The picture before removal is kept in `studio.sourceOrig` for "Bring the background back"; `showLogoSource` swaps the picture. A drop on the empty cover opens the Edit panel so the buttons are in view.
- **Our hosts** (owner 2026-11-18): `HOSTS` in `interviewKit.js` lists the show's own people: `@TateOnChain` ("Genfinity Host", photo framed at zoom 2.1, moved down 0.9, the owner's own settings) and Ryan Solomon ("Founder & CEO of Genfinity", photo as is). Their photos are files in `coverStudio/hosts/` imported through webpack (so they are public with the bundle). Choosing a person always fills the name and title lines and applies their photo framing (`personFraming`, `fillPersonWords`). **A new "Hosted by" piece starts with the first entry (Tate), not an empty placeholder** (`addHost(tab, who = HOSTS[0])`), with the name as the handle. **In a "Hosted by" piece, Tate's "Genfinity Host" replaces the words "Hosted by" before the microphone and is NOT repeated under the name** (owner 2026-11-18; `hostLabel` in `HOSTS`). A person without `hostLabel` (Ryan) keeps "Hosted by" and gets the title under the name; a host's two lines use `HOST_LINE` (larger, wider, lower than a guest's). The Guests tab shows the people under "Our hosts" with "Add as Hosted by" and "Add as a guest"; a guest's Photo panel has "Or use a host" thumbnails that put the person into that guest (`putHost(host, as, target)`). Do not name a helper `use...`: the hooks lint rule fails the build.
- **Main title letter spacing starts at -55** (owner 2026-11-18): `HEADLINE_SPACING`, used by `makeText` for `role: 'headline'` (every interview layout) and by the Text tab's "Add headline" preset.
- **Font picker** (`FontPicker`): a custom list, not a native select, because the owner wants the selected text to preview a font on hover and native options report no hover. `previewFont` sets the font without touching the history and puts the real one back when the pointer leaves or the list closes; `pickFont` commits through `setFont`.
- **Grain on one shape** (`studio.grain` on a shape, slider in its Edit panel). Drawn only where the shape is seen: its outline minus everything stacked above it (`paintShapeGrain`). On screen it is its own layer at screen pixels above the fabric canvas, redrawn after each canvas render; in the file it is drawn at cover pixels into the overlay. Never draw it inside the fabric canvas while editing: that canvas is resized by CSS and fine grain would ripple. Items above the shape are drawn to a separate sheet and cut out with `destination-out`, because fabric resets the blend mode for every object it renders.
- The border has a "Same border on every guest photo" tick box (`ringAll`, `setRing`): ticking it copies the selected guest's border to all, and later border changes go to every guest while it is ticked.
- **Shapes** are fabric `Rect`s (`studio.kind === 'shape'`, `studio.round` 0..1). **Text boxes** (the Interview pill, highlight bars) are `studio.box` on a text object, drawn by an instance override in `applyTextBox()` with caching off.
- **Layouts** (`INTERVIEW_LAYOUTS`) are data: applying one clears the cover and creates ordinary objects (placeholder guests, placeholder logos, text, panels). Placeholder logos (`studio.placeholder`) are filled by clicking a library logo or uploading while one is selected. A selected logo's Edit panel also carries the logo library (search + grid) and a file button, both of which swap the logo in place (`replaceLogo`). **Hidden file inputs must sit outside the tab panels**: the logo input used to live inside the Logos tab, so the Edit tab's file button had nothing to click and did nothing.
- **Logos**: "Remove plain background" (`removePlainBackground`) works inwards from the edges and only on a single flat colour. It is not a photo cut-out tool.
- The Genfinity wordmark for the "Brought to you by" line is `genfinity-wordmark-white.png` (supplied by the owner).
- Not built yet: background removal for PHOTOS (owner has to choose free self-hosted model vs paid service), and "Save to profile" for interview covers (the backend `upload-composed` route forces 1800x900, so the button is hidden in this tab; Download PNG works).
